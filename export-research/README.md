# Export Signal Lab public pilot

Static public offer and sample for company-level export-channel research.

## Files

- `index.html`: offer, scope, methodology, boundaries, email CTA.
- `sample.html`: five-company Poland CNC channel sample.
- `styles.css`: shared responsive styling.

## Facts and limits

- The sample is an illustrative public-research exercise, not a client case.
- No company was contacted and no personal contact data is included.
- Fit Score measures public evidence relevance, not credit, intent, reply rate, or sales probability.
- Email is the only intake path. Checkout and file upload are not enabled.

## Local verification

Open `index.html` in a browser at desktop and mobile widths. Confirm:

- all navigation targets exist;
- no horizontal overflow at 320 px;
- mailto links contain the intended fields;
- Chinese text is readable and not clipped.
