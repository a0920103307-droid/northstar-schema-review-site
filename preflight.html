What the browser checks

Fast signals for the failure modes that survive happy-path tests.

01

Destructive SQL

DROP, TRUNCATE, unqualified UPDATE or DELETE, type changes, and column removal.

02

Lock & rewrite

Index builds, constraint validation, SET NOT NULL, REINDEX, VACUUM FULL, and volatile defaults.

03

Transaction fit

Concurrent index and enum changes inside explicit transaction blocks.

04

Compatibility

Renames and NOT NULL additions that may break old application versions or existing rows.
