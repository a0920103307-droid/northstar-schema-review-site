Checklist scope

A focused preliminary checklist for one migration.

This checklist organizes possible text-pattern signals and questions to take to a qualified engineer. It cannot inspect production rows, traffic, or application behavior.

01

Data loss

Drops, destructive cleanup, unsafe backfills, and irreversible final steps.

02

Locks & rewrites

Type changes, constraint validation, index builds, and table-rewrite risks.

03

Compatibility

Expand/contract ordering, old application versions, renames, and nullable transitions.

04

Transaction fit

Concurrent-index wrappers, enum behavior, migration-runner assumptions, and ordering.

05

Rollback

Restore versus forward-fix choices, verification points, and stop conditions.

06

Evidence

File and line references, confidence, and questions for your engineer to verify.

Boundaries

Useful precisely because it stays narrow.

Included

  • PostgreSQL SQL and schema text
  • Rule-based signals with AI-assisted explanations; no human engineering sign-off
  • Deployment and rollback questions
  • Synthetic or redacted samples

Not included

  • Production database access or migration execution
